# Claude Projects

## `bible-bmw/` — La Bible BMW

Site encyclopédique statique sur les BMW, moteur par moteur. Ouvrir `bible-bmw/index.html` dans un navigateur (Three.js est chargé depuis jsDelivr).

- **Accueil** et **catalogue des moteurs** (filtres par famille, architecture et alimentation).
- **Fiche V8 S65** (M3 E90 / E92 / E93), en onglets :
  - *Présentation* : origine, architecture, carte d'identité, points de vigilance ;
  - *Fonctionnement 3D* : moteur animé, boîte DKG avec pédale et palettes, configuration d'origine ou compresseur, coupe détaillée d'un cylindre (air, essence, étincelle, flamme), son de V8 synthétisé, casse de bielle ;
  - *Pièces et références* : pièces classées par groupe du catalogue BMW, références avec leur source et leur statut de vérification, localisation dans la vue 3D ;
  - *Circuit* : piste fictive chronométrée.

Voir `bible-bmw/CONTRIBUER.md` pour ajouter des moteurs et des références.
